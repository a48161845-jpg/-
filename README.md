# Бот для Голодных игр (Starlight / Midnight)

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, заполните: `BOT_TOKEN`, `OWNER_IDS`, `STARLIGHT_CHAT_ID`, `MIDNIGHT_CHAT_ID`.
3. `python bot.py`

## Права бота
- В обоих чатах команд: админ с правами бан/ограничение, приглашение, удаление сообщений.
- В канале баллов (-1004327950960): админ с правом публикации и редактирования сообщений.
- Отключите Privacy Mode у бота (BotFather → /setprivacy → Disable), иначе он не видит команды с `.`

## Важно
- Бот узнаёт @username → ID только от тех, кто хоть раз писал в чате. Остальных при выдаче баллов вернёт в списке «не найдены».
- В выдаче баллов `@user -56` = минус 56, а `ID - 56` (дефис с пробелами) = плюс 56.
- Премиум-эмодзи в списках сохраняются, но бот отправит их как обычные, если у него нет доступа к кастомным эмодзи.
- Права: экономика/модерация/списки/игры/магазин/настройки — только владелец бота и кэпы (у кэпов свои для каждого чата). `.баллы`, `.расп`, `.календарь`, `.магазин`, `.сс`, `!о_баллы` доступны всем.
- `.сброс_баллов` просит подтверждение кнопкой.

## Поиск людей по @нику без их сообщений
Bot API не даёт списка участников, поэтому для этого нужен Telethon (вход под токеном бота):
1. https://my.telegram.org → API development tools → получите `API_ID` и `API_HASH`, впишите в `.env`.
2. `pip install telethon`, перезапустите бота. В каждом чате команды напишите любую команду (например `.помощь`) и выполните `.синхр`.
3. Бот должен быть админом в чатах. Дальше он сам собирает участников раз в сутки и находит @ники при выдаче баллов.

## Префиксы
Все команды работают с любым префиксом: `.` `!` `/` `,`. Команды с `+` и `-` пишутся как есть. Список команд: `.помощь`.
Заявки на вступление бот принимает сам (по умолчанию), это выключается в `.настройки` → Экономика → «Заявки». Если человек записан в список другой команды, заявка отклоняется.
