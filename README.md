# Бот для Голодных игр (Starlight / Midnight)

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, заполните: `BOT_TOKEN`, `OWNER_IDS`, `STARLIGHT_CHAT_ID`, `MIDNIGHT_CHAT_ID`, `DATABASE_URL`.
3. `python bot.py` (таблицы в базе создаются сами)

## Онлайн-база PostgreSQL
Все данные бота (баллы, списки, магазин, настройки, свои команды, сессия Telethon) лежат в онлайн-PostgreSQL, локальных файлов с данными нет.
1. Создайте базу на любом хостинге (Supabase, Neon, Railway, Render…) и скопируйте строку подключения в `DATABASE_URL`.
2. Перенос старых данных из `bot.db` (один раз, бот при этом остановлен): `python transfer_db.py` — спросит адрес онлайн-базы, перенесёт данные и сверит количество строк (или `python transfer_db.py bot.db "postgresql://…"`). Скрипт можно запускать повторно — дубли не создаются; старые баллы по командам он сам сливает в единый баланс.
3. После переноса `bot.db` можно удалить или оставить как резервную копию.

## Права бота
- В обоих чатах команд: админ с правами бан/ограничение, приглашение, удаление сообщений.
- В канале баллов (-1003957141651, https://t.me/hungergamesbm): бот — админ (чтобы получать сообщения канала). В этот канал бот ничего не пишет.
- Общий список баллов бот ведёт в том же канале (`LIST_CHANNEL_ID` по умолчанию равен `POINTS_CHANNEL_ID`): закреплённое сообщение, которое бот правит на месте.
- Отключите Privacy Mode у бота (BotFather → /setprivacy → Disable), иначе он не видит команды с `.`

## Баллы из канала
Кэпы вручную пишут в канал сообщения со строками `Ник (id) - баллы` (дробные: `1.5` / `0,5`; `Ник (id) -5` без пробела после минуса = минус 5). Бот читает новые и изменённые сообщения канала:
- баллы из сообщения прибавляются к балансу человека, правка строки (5 → 7) меняет баланс на разницу (+2), удаление строки из текста — отнимает её баллы;
- покупки в магазине бот снимает сам, при правках списка они не пропадают;
- общий список баллов бот ведёт сам в этом же канале (`LIST_CHANNEL_ID`); если кэп правит значение прямо в списке бота, баланс становится равным написанному (по id), а обычные сообщения кэпов прибавляются (один список без деления по командам: `1. @ник | id - баллы`; висит закреплённым, бот правит сообщение на месте и не отправляет заново);
- `.баллы` показывает баланс, `.сброс_баллов` обнуляет всех (кнопка подтверждения);
- проблемные строки (не понял число, один id дважды в сообщении) бот присылает создателю в личку;
- ограничение Telegram: если сообщение в канале **удалить целиком**, бот об этом не узнает — перед удалением очистите текст правкой.

## Важно
- Бот узнаёт @username → ID только от тех, кто хоть раз писал в чате. Остальных при выдаче баллов вернёт в списке «не найдены».
- В выдаче баллов `@user -56` = минус 56, а `ID - 56` (дефис с пробелами) = плюс 56.
- Премиум-эмодзи в списках сохраняются, но бот отправит их как обычные, если у него нет доступа к кастомным эмодзи.
- Права: экономика/модерация/списки/игры/магазин/настройки — только владелец бота и кэпы (у кэпов свои для каждого чата). `.баллы`, `.расп`, `.календарь`, `.магазин`, `.мид`, `.стар`, `!о_баллы`, `.снос` доступны всем.
- Баллы — один баланс на человека. Каждый закреплён за основной командой (где был изначально): в её блоке он стоит в списке в канале.
- `.мид` (в чате Starlight) и `.стар` (в чате Midnight) выдают ссылку на другую команду.
- С 20:00 до 21:00 (МСК) вход в команды закрыт (Голодные игры); заявки по ссылке бота ждут и принимаются после 21:00. Заявки по чужим ссылкам и открытые ссылки без заявок бот не контролирует.
- Перед игрой бот исключает из чата всех, кто состоит в другой команде и не записан в список этой команды, а записанных в список — из чата противоположной команды (кэпы, админы и владелец не трогаются).
- Набранный список бот закрывает и сбрасывает сам; состав помнит до конца игры.
- Магазин: `.+товар 15 Название | описание`; автоматически бот выдаёт только «снять варн», остальное вручную — тегаются кэпы с включённым «Тег при выдаче товаров» в `.права`.
- `.сброс_баллов` просит подтверждение кнопкой.
- Первый запуск после обновления сам переносит старые баллы (по командам минус траты) в единый баланс.

## Поиск людей по @нику без их сообщений
Bot API не даёт списка участников, поэтому для этого нужен Telethon (вход под токеном бота):
1. https://my.telegram.org → API development tools → получите `API_ID` и `API_HASH`, впишите в `.env`.
2. `pip install telethon`, перезапустите бота. В каждом чате команды напишите любое сообщение.
3. Бот должен быть админом в чатах. Дальше он сам собирает участников каждый день в 00:00 МСК и находит @ники при выдаче баллов.

## Префиксы
Все команды работают с любым префиксом: `.` `!` `/` `,`. Команды с `+` и `-` пишутся как есть. Список команд: `.помощь`.
Заявки на вступление по ссылке бота принимаются автоматически (выключается в `.настройки` → Экономика → «Заявки»). Если человек записан в список другой команды, заявка отклоняется.

## Создатель
Бот нигде не тегает создателя (OWNER_IDS): ни ссылкой, ни @ником. Если @ник создателя (`OWNER_USERNAMES`, по умолчанию `n0irxs`) попадает в ответ бота — например, в свои команды через `{args}` или в причину наказания, — он выводится обычным словом без @, уведомления нет.

## Ежедневная синхронизация (00:00 МСК)
Бот обновляет участников чатов команд, убирает из списка баллов тех, кто не состоит ни в одной команде, и добавляет новых. Создатель/овнеры (`OWNER_IDS`) и владельцы чатов не убираются. Итог приходит создателю в личку.

## Вход перед игрой
Игра идёт с 20:00 до 21:00 (`GAME_LENGTH_MIN = 60`): ограничения «перед игрой» (отказ во входе, кик людей из противоположной команды) действуют до 21:00, а не до 21:30. Кик перед игрой работает как раньше.

## Ники в списке баллов
Всё привязано только к id: из канала бот берёт id и баллы, ник в строке не важен. Подпись `@ник` в общем списке обновляется не чаще раза в 24 часа (при смене ника он подтянется в течение суток; ежедневная синхронизация в 00:00 тоже его обновляет).

## Список баллов в канале (без привязки к номеру сообщения)
Баллы берутся из **всех** сообщений канала: каждое новое или изменённое сообщение кэпа учитывается отдельно, номер сообщения не важен. Сообщение со списком бот запоминает сам: при первом запуске берёт закреплённое сообщение канала (если в нём строки `Ник | id - баллы`), иначе создаёт своё и закрепляет. Если сообщение удалили или оно «уехало», бот отправит список заново, баллы при этом не теряются (они в базе). `LIST_MESSAGE_ID` в `.env` необязателен (0 = автоматически). Для правок боту нужен админ-доступ к каналу с правом редактировать сообщения.

## Премиум-эмодзи
Файл `premium_emoji.py`: впишите ID премиум-эмодзи напротив обычного — оно заменится во всех сообщениях бота и на всех кнопках (на кнопке эмодзи становится иконкой, надпись остаётся).
- Цвета кнопок (зелёные/красные/синие) — раздел «ЦВЕТА КНОПОК» в `premium_emoji.py` (нужен свежий aiogram и клиент Telegram с поддержкой цветных кнопок).

## ЧС команд
`.чс` (ответом / @ником / ID) — в ЧС команды этого чата: данные сохраняются в таблице `blacklist`, человек банится навсегда и получает в личку сообщение, что он в ЧС команды. `.массчс` — сразу в обе команды, `-чс` — убрать. Если ЧС дала основная команда, а человек состоит в другой, то через 7 дней другая становится основной (проверка раз в час, итог приходит создателю). Если он не состоит ни в одной команде — ему предлагают вступить в команду без ЧС. Заявки и повторные входы людей из ЧС отклоняются; `.разбан` для них не работает — только `-чс`. Нужно право «Бан».

## Тематические списки
`+темсписок 1` + шаблон (ответом на сообщение со списком; картинка идёт вместе со списком в подписи). Места — ники `St | Имя` / `Mn | Имя`, значение после `CAP :` (кэп — обычное место, без 👑) или помеченные `@`. Форматирование шаблона сохраняется. По 👍 бот ставит человека на место, чей ник содержится в его имени или юзернейме (регистр, ё/е, шрифты не важны): вместо ника — его имя ссылкой на профиль (@юзернейм, иначе ID); моно на занятом месте снимается. `.темтест 1 Имя` — проверка.

Сердечко сразу после ника входит в место и заменяется именем нажавшего. Явная пометка места — `[St | Имя 🤍]`. Совпадение: ник целиком, либо имя / фамилия по отдельности (в любом порядке), либо хвост после `St |` / `Mn |`; если подходит несколько мест, бот ничего не угадывает.
